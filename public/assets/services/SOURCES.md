# Service card screens

The screens inside the drawn phones on the home page's service cards
(`components/home/ServiceArt.tsx`). Two are real client menus — both venues are Dimonova
clients, both menus were built and are run by Dimonova, and the captures were taken on the
owner's request. The third is designed, not captured.

| File | Source | How it was taken |
|------|--------|------------------|
| `menu-balamo.webp` | https://carta.balamorestaurante.es — the "Carta" tab, "Raciones" category | Playwright, 390×844 phone viewport at 2×, the welcome popup closed; cropped to the top 780×1600 (the phone screen's own 116:238 ratio), resized to 464px wide |
| `menu-balamo-dish.webp` | Same site — the detail sheet for "Lomo de bellota" | Same capture; the sheet's photograph, name, price and description cropped out (y 240–1000), resized to 448px wide |
| `reviews-mock.webp` | **Not a capture.** A rating screen designed for the card: fictional venue ("La Marea"), invented waiter names, an invented comment. Generated by `scripts/generate-reviews-mock.mjs` | Playwright renders the script's own HTML at 390×800, 2×, then sharp resizes it to 464px wide. Re-run the script after editing it |
| `ordering-leclub.webp` | https://carta.leclubtenerife.com — "Carta de Comida", with the first dish ("Gilda") added to the cart so the cart bar shows | Playwright, same viewport; cropped to 780×1600 from y=60, which keeps the cart bar and most of the header, resized to 464px wide |

The QR code on the ordering card is not an image: it is a real version-2 QR for
`https://carta.leclubtenerife.com`, generated once with the `qrcode` npm package and stored as
module rows in `ServiceArt.tsx`.

Captured 2026-09-10. Re-capture when either menu's design changes noticeably; the crop sizes
above are what `ServiceArt.tsx` assumes.
