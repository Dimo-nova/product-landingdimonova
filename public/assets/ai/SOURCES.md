## The one edit

`openai.svg` is not byte-identical to the file downloaded. The OpenAI brand page serves its
mark inside a clear-space diagram: two copies of the blossom, one of them overlaid with faint
construction guides, inside a framing rectangle. The saved file keeps **only the clean copy's
path, unmodified**, with the `viewBox` set to that path's own bounding box, and `fill` changed
to `currentColor` so the mark can be rendered in a single flat colour as the guidelines allow.
No point of the artwork was moved, stretched or cropped.

## Open question for the owner

Each of these companies publishes trademark usage guidelines, and some require written
permission before their mark appears on a commercial site, even for nominative use. Nobody has
sought that permission. If it matters, the fallback is the previous treatment: the provider's
name as plain text, which needs no licence at all.
